# Security Policy

## Overview

agent-skill-security is an open-source security scanner designed to identify potential risks in AI Agents, Skills, Plugins, and automation scripts.

The project helps developers detect security issues before deploying AI-powered workflows.


## Supported Security Checks

The project focuses on detecting:

- Hardcoded API keys and credentials
- Unsafe shell command execution
- Suspicious network requests
- Risky file system operations
- Potential prompt injection patterns

Dependency and supply-chain analysis is planned work and is not currently a
supported detection category.


## Supported Versions

Currently supported versions:

| Version | Supported |
|---|---|
| v1.x | Yes |


## Reporting a Vulnerability

If you discover a security issue, please do not create a public issue.

Use GitHub's private vulnerability reporting form:

https://github.com/jilejiang10-create/agent-skill-security/security/advisories/new

The repository must keep private vulnerability reporting enabled so this form
remains available. Do not include vulnerability details in a public issue.

Please report vulnerabilities privately with:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation


## Response Timeline

Security reports will be reviewed by the maintainers.

The response process includes:

1. Confirming receipt of the report.
2. Evaluating the security impact.
3. Investigating affected components.
4. Preparing fixes when necessary.
5. Publishing security updates when available.


## Security Scope

This project focuses on security analysis for:

- AI Agent Skills
- Plugins
- Automation Scripts
- Developer Tools
- LLM-based Applications


## Maintainer Response

Maintainers will review security reports and provide updates during the investigation and resolution process.

Thank you for helping improve Agent Skill Security.
