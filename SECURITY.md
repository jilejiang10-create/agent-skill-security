# Security Policy

## Overview

agent-skill-security is an open-source security scanner designed to identify potential risks in AI agents, skills, plugins, and automation scripts.

## Supported Security Checks

The project focuses on detecting:

- Hardcoded API keys and credentials
- Unsafe shell command execution
- Suspicious network requests
- Risky file system operations
- Potential prompt injection patterns
- Unsafe third-party dependencies

## Reporting a Vulnerability

If you discover a security issue, please do not create a public issue.

Please report vulnerabilities privately with:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation

## Maintainer Response

Maintainers will review security reports and provide updates as soon as possible.
